# Content Drafts

This directory contains the English-normalized reference documentation for the project's narrative and audio content.

## Scope

- Museum scene content
- Mainland Home scene content
- Subtitle cue references
- On-screen text separate from spoken narration
- Ambience planning and search terms
- Audio source and licence tracking
- Unity integration notes for the content team

These files are documentation and planning materials only. They are intentionally outside Unity's `Assets/` directory and are not imported at runtime.

## Branch

This branch is `assets/content`, created from `assets/audio`. The parent branch contains the original audio reference set. The interaction branch contains adjusted assets used for interaction testing; this branch does not replace or delete those files.

## Status

The scripts and cue timings are drafts for team review. Audio source, licence, final recording, and final mix status must be confirmed before public demonstration or release.

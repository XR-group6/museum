# Original Scene Audio Reference Set

This directory stores the original audio reference set for the project's first three scenes.

- Scene 01, Scene 02, and Scene 03 audio files are included here for team content management and later production reference.
- Filenames have been normalized to English.
- These files are reference materials only. They are intentionally outside Unity's `Assets/` directory and are not imported as runtime assets.
- The audio versions on the `interaction` branch are adjusted/integrated variants used for interaction testing. This reference set does not delete or overwrite those files.
- These MP3 files are currently internal temporary materials. Before final use, the team must confirm source, license/permission, editing, and volume settings for each file.
- System files such as `.DS_Store` are intentionally excluded.

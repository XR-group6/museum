# 字幕语言选择：提交说明与验证

## 功能

- 在场景 1 检测到 SteamVR 有效追踪后显示“中文 / English”选择面板；任一手柄指向按钮并按扳机可选择。
- 选择完成后开始场景 1 原有旁白流程，中文音频保持不变。
- 当前播放会话内保留语言选择，跨场景不重置；重新运行默认需要再次选择。
- 覆盖前三幕旁白、对白、场景 1 操作提示及进入记忆确认文字，并覆盖后续自由探索提示。
- `VRSubtitle` 只翻译文字，保留现有位置、跟随模式、字体、字号、宽度、缩放、背景和字幕时序；英语使用原组件的自动换行与背景高度计算。
- 新增或修改的中文文本如未登记英文翻译，会保留原文，需要补充 `SubtitleLanguage` 中的翻译表。

## 文件与依赖

新增：`SubtitleLanguage`、`LocalizedUIText`、`InitialLanguageSelector`、`LanguagePanelUI.shader` 及其 `.meta`。

修改：`VRSubtitle`、`SceneOneNarration`；在 Graphics Settings 的 Always Included Shaders 中注册启动选择面板 Shader，避免构建时剔除。

使用现有 SteamVR `GrabPinch` 动作和 Unity UI，无新增 Package。语言选择面板在运行时创建，不需要修改 `.unity` 场景文件。

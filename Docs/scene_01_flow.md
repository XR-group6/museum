# 场景 1：香炉记忆入口

进入 `scene_01`，加载音频后先播放「博物馆回音+人声」的前 10 秒，期间不显示字幕或交互提示。随后停止背景音并播放「场景1 香炉1」，按介绍音频的 0、5.65、14.2 秒切换三段介绍字幕。香炉保持静止，介绍期间不显示交互提示、不能触发动画。介绍结束后才显示右手触碰引导，将右手靠近香炉并重新按下扳机（GrabPinch）。

这次交互同时启动 `TL_censer_interaction` 和「场景1 香炉2」，随后接着播放「场景1 香炉3」，保留两段台词字幕。动画在约 8.133333 秒完成溶解，此时隐藏整个效果对象、原始香炉渲染器和香炉碰撞体；播放结束不再复位或显示香炉。

溶解完成后，在当前视线前方显示「是否愿意进入香炉的记忆」，下方只有一个「是」按钮。右手射线指向按钮时变绿，按扳机确认；也可以靠近按钮按扳机。编辑器 Game 窗口支持鼠标点击按钮。按钮在运行时创建于 `SceneAudioTimeline/EnterCenserMemory`，位置固定，朝向随观察者调整。

只有确认「是」才跳转 `scene_02`。若确认时香炉 2、3 的台词还未播完，会等待配音完成再跳转；不确认则留在场景 1。提前按住扳机不会在介绍结束时自动触发，需要重新按下。

实现：`SceneOneNarration.cs` 控制叙事与入口，`RightController.cs` 处理右手交互，`CenserScenePlayback.cs` 负责动画和永久隐藏。场景保存了 `censerPlayback` 引用和溶解完成时间。安装效果的编辑器菜单也默认关闭自动播放。

验收：

1. 进入场景时香炉静止，先播放 10 秒博物馆背景音，不显示字幕；之后播放香炉 1 配音和介绍字幕，介绍结束后才显示右手提示。
2. 介绍期间触摸并按扳机不会触发；播完后重新按扳机仅触发一次。
3. 交互开始浮空溶解，香炉 2、3 按顺序播放，台词字幕同步。
4. 约 8.13 秒后香炉和粒子效果隐藏，原模型不恢复，问题和「是」出现。
5. 等待超过原 Timeline 的 10.5 秒总时长，香炉仍不出现，不自动跳转。
6. 右手射线悬停变绿，按扳机跳转场景 2；快速确认也不会截断配音。

已使用 Unity 2022.3.62f3 自带 Roslyn 和项目实际编译参数通过运行时、编辑器脚本编译。VR 真机交互及画面布局需要在头显中验收。

双眼渲染：OpenVR 使用 Multi Pass（`StereoRenderingMode: 0`），以兼容香炉现有 Shader Graph 材质。自定义粒子 Shader 补齐了立体输出初始化和片元阶段的眼睛索引设置。Multi Pass 会增加渲染开销；修改后退出 Play 并重新进入，让 XR 重新初始化。左右眼中的香炉和溶解效果仍需头显验证。

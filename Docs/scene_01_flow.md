# 场景 1：香炉记忆入口

选择字幕语言后，播放博物馆背景音的前 5 秒，无字幕。随后停止背景音，显示“请用右手触摸并握住香炉。”，等待右手靠近香炉并重新按下 GrabPinch 扳机；提前按住不会触发。

触碰后播放香炉 1，三段介绍字幕仍在音频的 0、5.65、14.2 秒切换。此阶段不播放消融动画。右手激光指向香炉，按住扳机并转动手柄即可旋转欣赏，松开停止。使用与台胞证相同的手柄旋转差值方式，围绕香炉中心旋转。摄像机前方墙面显示“试试用右摇杆的激光长按扳机转动香炉。”，支持中英切换。墙面无碰撞体时临时查询房间网格，不保存改动。

香炉 1 播完后隐藏旋转提示，显示“是否愿意进入香炉的记忆”及“是”按钮，面板跟随头显位置与朝向。确认前仍可欣赏香炉。不确认则留在场景 1。

按下“是”后关闭确认界面、停止旋转并恢复香炉原始姿态，再同时启动原 TL_censer_interaction 和香炉 2。依次播放香炉 2“欸，你可认得我？”、香炉 3“或许，你愿意听听我渡海而来的故事？”，各自同步字幕。原动画、粒子、曲线和音频资源均不修改。约 8.133333 秒完成消融后永久隐藏，等待两段配音与消融均完成，再进入 scene_02。

验证：运行时脚本编译检查；实际头显中需确认墙面文字位置、射线命中、按住旋转、松开停止、记忆按钮及完整转场。

旋转命中直接查询场景绑定的香炉碰撞体（包括 Trigger），避免全局忽略 Trigger 导致无法命中。
